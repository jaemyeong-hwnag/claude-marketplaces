# 완성도 진단

규칙 원본: [`references/completeness-rules.md`](../../references/completeness-rules.md) — 판정 원칙 `Q-01` ~ `Q-07`, 프로젝트 타입, 핵심 항목.

```bash
PC="${CLAUDE_PLUGIN_ROOT}/scripts/project-completeness.sh"
```

**읽기 전용이다.** 파일을 만들거나 고치지 않는다. 적용은 `completeness-apply`, 실측 수치는 `service-health-review` 가 맡는다.

## 1. 자동 탐지 — 스크립트가 한다

```bash
"$PC" detect .
```

Bash 로 파일을 하나씩 뒤지지 않는다. 결과 JSON 하나로 시작한다.

| 필드 | 쓰는 법 |
|---|---|
| `projectType` | `null` 이면 사용자에게 묻는다 (`mobile` · `game` · `embedded` · `data` 는 추론하지 않는다) |
| `passed` · `failed` | 저장소 구조로 확인했다. **다시 확인하지 않고** 그대로 쓴다 |
| `unknown` | 로직이 판정을 보류했다. 이유가 `evidence` 에 있다 |
| `hints` | 흔적일 뿐 판정이 아니다 (`Q-02`) — 3단계에서 확인한다 |

`monorepo` 면 패키지를 고르게 하고 그 디렉터리로 다시 `detect` 한다.

## 2. 측정 범위를 고르게 한다

```bash
"$PC" scope --type <projectType>
```

해당 없는 항목을 뺀 목록이 나온다. 방식은 ⚡ 자동 · ▶️ 실행 · 💬 질문. `AskUserQuestion` 으로 범위를 묻되 첫 옵션은 **"모두 측정"**, 다음은 "자동만" · "자동 + 실행" · "축 고르기". 사용자가 범위를 이미 말했으면 묻지 않는다.

## 3. 고른 범위만 잰다

| 방식 | 어떻게 |
|---|---|
| ⚡ `passed` · `failed` | 1단계 결과 그대로 |
| ⚡ `hints` · `unknown` | 흔적이 있으면 그 코드를 **읽고** 동작하는 구현인지 본다. 없거나 애매하면 질문으로 넘긴다 |
| ▶️ 실행 | 도구를 실제로 돌려 수치를 얻는다 (`scope` 의 소요 시간을 먼저 알린다). 돌릴 수 없으면 이유와 함께 미통과 |
| 💬 질문 | **한 번에 모아서** 묻는다. 답이 없으면 미통과 |

전제가 구조적으로 없는 항목(AI 로 코드를 만들지 않으면 `code.ai-provenance`, IaC 가 없으면 `security.iac-scan`)은 N/A 로 선언하고 근거를 남긴다 (`Q-04`).

## 4. 채점

```bash
"$PC" score --type <projectType> --pass <통과 id,…> --na <선언 N/A id,…>
```

모르는 id 를 주면 멈춘다 — id 는 `scope` 출력에서 복사한다.

## 5. 보고

```
위험도: <score 결과> (핵심 n/m)      실천 범위: <등급> (달성률 %, 적용 N항목)
축별: 코드 x/y · 테스트 x/y · 보안 x/y · 성능 x/y · 접근성 x/y · 운영 x/y · 서비스 x/y · 제품 x/y

핵심 공백: <id — 한 줄>
가장 비어 있는 축: <축> — <미통과 3개>
다음 한 걸음: <그 축의 레시피 1 ~ 3개> — "적용해줘" 로 completeness-apply
확인 필요: <판정 보류 항목과 이유>
```

- 위험도와 실천 범위를 **같이** 말한다. 범위만 보고 "위험하다" 고 하지 않는다 (`Q-03`)
- 다음 한 걸음은 **한 축만** (`Q-07`). 레시피가 있는 항목은 `scope` 에 `· 레시피` 로 표시돼 있다
- SLO · 온콜 · 포스트모템이 통과했으면 `service-health-review` 로 실제 수치 판정을 제안한다 (`Q-05`)

## 하지 않을 것

- 흔적만 보고 통과시키기 · 답이 없는 질문을 통과로 세기
- "우리는 안 해서" 를 N/A 로 받기
- 진단 중에 설정 파일을 만들거나 도구를 설치하기
