# common-design-soundness-review 테스트

`scripts/design-soundness-validate.sh` 의 회귀 테스트다. 규칙 · 스크립트를 고치면 여기부터 돌린다.

## 실행

```bash
test/design-soundness-validate.test.sh          # 전체
test/design-soundness-validate.test.sh TC-D8    # ID 접두사로 필터
```

종료 코드 0 이면 전체 통과다. bash · jq · awk 만 쓴다. 기록은 임시 `CLAUDE_PLUGIN_DATA` 에 쓴다.

## 수동 확인

`claude -p`(비대화)에는 `ExitPlanMode` 도구가 없어 eval 로 `DD-31` 을 볼 수 없다. 구현을 바꾸면 대화형 세션에서 한 번 확인한다.

1. 플러그인을 설치한 프로젝트에서 `claude --permission-mode plan` 으로 계획을 세우게 한다
2. 플랜 모드를 나가려 할 때 `PreToolUse:ExitPlanMode hook error: 설계 검토 전 (… DD-31)` 이 보이는지
3. Claude 가 `design-soundness-reviewer` 를 부르고 계획을 고친 뒤 다시 나가는지
