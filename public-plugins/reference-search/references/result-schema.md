# 결과 형식

출처별 에이전트(`*-searcher`)는 이 형식으로만 돌려준다. 스킬은 이 형식을 전제로 병합하고, `reference-reviewer` 는 이 형식을 받아 판정한다.

## 에이전트가 돌려주는 것

````
## <에이전트 이름>

검색어: <실제로 쓴 검색어들, 출처마다> · 검색일: <YYYY-MM-DD> · 필터: <기간 · 언어 · 정렬>
출처: <조회한 출처와 건수> · 실패: <출처 — 이유 (429 · 응답 없음 · 키 필요 · 봇 차단)>

| # | 제목 | 저자 · 회사 | 연도 | 게재처 | 식별자 | 상태 | 요지 | 찾은 경로 |
|---|---|---|---|---|---|---|---|---|
````

| 칸 | 쓰는 법 |
|---|---|
| 제목 | 원문 제목 그대로. 번역하지 않는다 |
| 저자 · 회사 | 논문은 제1저자 외 N명, 기업 자료는 회사 이름 |
| 연도 | 게재 연도. 블로그 · 발표는 날짜(YYYY-MM-DD)까지 |
| 게재처 | 저널 · 학회 · 프리프린트 서버 · 블로그 이름 |
| 식별자 | DOI(`10.xxxx/…`) → arXiv ID(`arXiv:…`) → URL 순으로 있는 것 하나 이상. **도구 결과에 나온 값만 쓴다** |
| 상태 | 아래 상태 값 중 하나 |
| 요지 | 이 요청과 관련된 내용 한 줄. 초록 · 본문을 읽은 것만. 제목만 봤으면 `제목만 확인` |
| 찾은 경로 | `reference-search.sh openalex` · `WebSearch site:netflixtechblog.com` 처럼 재현할 수 있게 |

못 찾았으면 표 대신 `결과 없음` 과 시도한 검색어를 적는다. 빈 칸을 지어내 채우지 않는다.

## 상태 값

| 값 | 뜻 |
|---|---|
| `심사 완료` | 동료 심사를 거친 저널 · 학회 논문 |
| `프리프린트` | 심사 전 원고 (arXiv · bioRxiv · SSRN …) |
| `학회 투고` | OpenReview 등 심사 중이거나 심사 결과가 공개된 투고 |
| `학위논문` | 석사 · 박사 학위논문 |
| `보고서` | 정부 · 기관 · 연구소 보고서, 워킹 페이퍼 |
| `표준` | RFC · W3C · ISO · NIST 등 |
| `공식 문서` | 제품 · 프로젝트의 공식 문서 · 릴리스 노트 |
| `기업 블로그` | 회사 기술 블로그 · 엔지니어링 글 |
| `발표` | 컨퍼런스 · 밋업 발표 영상 · 슬라이드 |
| `장애 보고` | 사후 분석 · incident report |
| `코드` · `이슈` | 저장소 · 코드 · 이슈 · 설계 문서(KEP · PEP 등) |
| `커뮤니티` | Hacker News · Reddit · Stack Overflow · 뉴스레터 |

철회 · 우려 표명이 확인되면 상태 뒤에 `· 철회` 또는 `· 우려 표명` 을 붙인다.

## 검증 결과 (`reference-reviewer`)

존재와 지지를 따로 판정한다. 실재하는 문헌도 인용한 문장을 다 떠받치지 않는 경우가 많다 (`reference-search-methods.md` `P26`).

| # | 존재 | 지지 | 근거 |
|---|---|---|---|

| 칸 | 값 | 뜻 | 스킬이 하는 일 |
|---|---|---|---|
| 존재 | `확인` | 식별자가 있고 제목 · 저자 · 연도가 맞다 | 그대로 쓴다 |
| 존재 | `불일치` | 식별자는 있지만 메타데이터가 다르다 | 바른 값으로 고친다 |
| 존재 | `없음` | 식별자 · 페이지가 없다 | 뺀다 |
| 존재 | `철회` | 철회 · 우려 표명이 있다 | 남기되 상태에 표시한다. 결론의 근거로 쓰지 않는다 |
| 지지 | `지지` | 원문이 요지를 그대로 말한다 | 그대로 쓴다 |
| 지지 | `부분` | 원문이 요지의 일부만 말한다 | 요지를 원문 범위로 좁힌다 |
| 지지 | `아님` | 원문이 요지와 다른 말을 한다 | 요지를 고치거나 뺀다 |
| 둘 다 | `미확인` | 확인하지 못했다 (네트워크 · 접근 제한 · 원문 못 엶) | 남기되 `미확인` 표시 |

## 최종 출력

맨 위에 기준일 · 검색 범위(기간 · 언어 · 깊이 · 띄운 에이전트) · 건수(찾음 → 병합 뒤 → 검증 통과) · 빠진 출처를 적는다. 그다음 결과를 상태별 또는 주제별로 묶은 표, 마지막에 요청에 대한 답(무엇이 알려져 있고 무엇이 미확인인지)을 쓴다.
