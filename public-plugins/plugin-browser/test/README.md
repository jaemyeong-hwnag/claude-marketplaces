# plugin-browser 테스트

`scripts/plugin-browser.sh` 의 회귀 테스트.

## 실행

```bash
test/plugin-browser.test.sh          # 전체 (~3분 — 폭 19가지 × 화면 8종 × 모호 폭 2, pty 조작)
test/plugin-browser.test.sh TC-W     # ID 접두사로 필터
```

카탈로그는 `PLUGIN_SEARCH_CATALOG` 로 주입하고(대상 마켓 `m`) 엔진은 형제 디렉터리의 `plugin-search-install` 을 쓴다. 실제 설치는 하지 않는다 (`--dry-run`).

- **폭** — 줄의 표시 폭을 스크립트의 표가 아니라 perl 의 `\p{East_Asian_Width=…}` 로 따로 잰다. 같은 표로 재면 같은 실수를 놓친다. VS16 이 붙은 글자는 두 칸으로 센다
- **픽스처** — 아주 긴 이름, 한글 이름, 전각 · 한자 · 결합 문자 · 이모지 · VS16 · 가운뎃점(모호 폭), 제어 문자가 든 설명, 긴 태그 설명, 스크롤이 생기는 25개 채움 항목
- **대화형** — `script` 로 pty 를 만들고 `stty rows · cols` 로 크기를 정한 뒤 키를 시간차로 넣는다. 반응 없는 화면이 테스트를 붙잡지 않게 40초 감시. `script` 가 없으면 SKIP
- 필요한 것: `bash` · `jq` · `perl` (· `script`)
