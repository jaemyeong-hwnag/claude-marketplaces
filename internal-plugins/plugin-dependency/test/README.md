# 의존성 테스트

`scripts/validate-dependency.sh` 의 회귀 테스트. 의존성 규칙이나 스크립트를 고치면 여기부터 돌린다.

범위 문자열 형식(`V-11`)은 `plugin-versioning/test/` 가 본다. 섞지 않는다.

## 실행

```bash
test/validate-dependency.test.sh          # 전체
test/validate-dependency.test.sh TC-P4    # ID 접두사로 필터
```
