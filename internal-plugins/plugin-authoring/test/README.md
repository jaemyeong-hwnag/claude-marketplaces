# 작성 규칙 테스트

`scripts/validate-authoring.sh` 의 회귀 테스트. 작성 규칙이나 스크립트를 고치면 여기부터 돌린다.

이름은 `plugin-naming/test/`, 위치는 `marketplace-directory-structure/test/`, 버전은 `plugin-versioning/test/` 에 있다. 섞지 않는다.

## 실행

```bash
test/validate-authoring.test.sh          # 전체
test/validate-authoring.test.sh TC-A2    # ID 접두사로 필터
```

종료 코드 0 이면 전체 통과다.
